# 存储与恢复边界

测试机原 Android 系统已被替换。最终 GPT 保留必要固件/启动/恢复等前部区域，将可回收空间合并为约57.74 GiB的连续 ext4 根分区，在本机布局中为 p53；重启读写已验证。

**不发布通用 GPT 写入脚本或扇区表。** 此布局依赖本机容量、固件固定地址依赖和原 Recovery 的实际行为。p53、容量及地址不能直接套用到其他手机。

本机保留第三方 Recovery、原厂固件/校准分区、离线备份和已验证回退镜像。没有宣称存在原 userdata 的完整备份。公开仓库不包含任何设备专属备份、GPT二进制、NV、persist或内存转储。

启动依赖此前已实机验证的替代 aboot 与匹配 Recovery 封装。修改镜像尾部沿用的 OEM 签名并不对修改后的镜像有效；成功启动不代表任意 OPPO 可以绕过签名校验。此仓库不提供通用解锁或一键刷写包。

原 Android 根文件系统已删除，不能仅刷回旧 Android boot 就声称恢复完成。若需要恢复，应使用与设备匹配的完整恢复方案；本仓库仅公开研究资料。
